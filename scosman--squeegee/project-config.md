# Squeegee — Repo Guide

Squeegee is a native **macOS menu bar app** that closes stale windows of other apps. The user sets per-app rules ("close Finder windows 6 hours after I last used them"), and Squeegee closes each window when its time is up. It works per **window**, not per process. Private, local, macOS 15+.

**Current stage:** Phases 1-9 are built. The app is feature-complete for V1: Engine, Persistence, Presentation, SystemBridge, AppCore, all UI modules (SharedUI, MenuBarUI, OnboardingUI, SettingsUI, AppShellUI), and the release pipeline (`scripts/release.sh` + `make release`). The hardware checkpoint is done except the timer/energy/login-item steps (on the backlog). `make ci` is green.

## Module map (dependency DAG)

```
L0  Engine            (Foundation only; pure)
L0  Presentation      (Foundation; depends Engine)
L1  Persistence       (SwiftData; depends Engine)
L1  SystemBridge      (AppKit, AX, CG, ServiceManagement; depends Engine)
L2  AppCore           (depends Engine, Presentation, Persistence)
L3  SharedUI          (SwiftUI; depends Presentation, AppCore)
L3  MenuBarUI         (AppKit; depends Presentation, AppCore)
L3  OnboardingUI      (SwiftUI; depends SharedUI, AppCore)
L3  SettingsUI        (SwiftUI; depends SharedUI, AppCore, Persistence)
L3b AppShellUI        (SwiftUI; depends OnboardingUI, SettingsUI)
--  ManualTestKit     (Foundation; pure) + executable manual-tests-check
--  TestSupport       (test-only target at Tests/TestSupport)
L4  App target        (depends AppShellUI, MenuBarUI, AppCore, SystemBridge, Persistence)
```

- `AppCore` does **not** depend on `SystemBridge`. It sees only the port protocols (in `Engine`). The app target wires `SystemBridge` live types into `AppCore`.
- `ManualTestApp` depends on `SystemBridge`, `Engine`, and `ManualTestKit`.

## Conventions and gotchas

- **macOS 15+ only.** Swift 6, strict concurrency, warnings-as-errors.
- **Swift-package-first.** All logic lives in `Packages/SqueegeeKit` and builds/tests with `swift build` / `swift test`. The app target is only the composition root.
- **No third-party dependencies.** The package has zero external dependencies.
- **Bundle ID is locked:** `net.scosman.squeegee`. Do not change it (TCC grants persist against it).
- **Signing/TCC:** Accessibility grants are bound to the code signature. Ad-hoc builds lose the grant on every rebuild. Local runs use the team's Apple Development identity (`make run-app`, `make run-manual-tests`). Reset a grant with `tccutil reset Accessibility net.scosman.squeegee`.
