# AGENTS.md — Technical Article Quality Standards

> **Audience**: AI coding assistants and human contributors.
> Read this before writing or expanding any `.md` file in this repository.

---

## Language & Spelling

- **American English only** — `color`, `behavior`, `initialize`, never `colour`, `behaviour`, `initialise`
- Use clear, direct technical prose — no filler, no hedging, no marketing language
- Prefer active voice: "The ULA generates video" not "Video is generated by the ULA"
- **Hexadecimal**: Use Z80 convention — `#FE`, `#7FFD`, or `$FE`, `$7FFD` for I/O ports and memory addresses. Do NOT use C-style `0xFE` unless explicitly within a C code block.
- **Port addresses**: Always state the port address and its decoding bitmask. The ZX Spectrum uses partial address decoding — many ports are mirrored across address ranges. Document which address lines are actually decoded.

---

## Three-Track Awareness

This knowledge base covers three parallel hardware streams that share the Z80 CPU and much of the software ecosystem:

| Track | Scope | Primary Models |
|---|---|---|
| **Original** | Sinclair/Amstrad era (1982–1992) | 16K, 48K, 128K, +2, +2A, +3 |
| **Soviet** | Post-Soviet clones (1989–present) | Pentagon, Scorpion, Kay, ATM Turbo, Profi, dozens more |
| **New Gen** | Modern hardware (2010s–present) | ZX Spectrum Next, Sprinter, ZX Evolution (TS-Conf/Baseconf) |

Every article must note which track(s) it applies to. When behavior differs between tracks, document each variant explicitly. Soviet clones are NOT second-class citizens — the ZX Spectrum ecosystem in the post-Soviet space was (and remains) larger than the original Western market.
