## What this is

A research workspace (not a git repo) for reproducing Eon Systems' "digital fly brain" and connecting it to a simulated body. It wraps two upstream projects rather than reimplementing them:

- `external/fly-brain/` — official clone of `github.com/eonsystemspbc/fly-brain` @ `a3db62f` (GPL-2.0-or-later). Whole-brain LIF model (Shiu et al. 2024) on FlyWire v783: 138,639 neurons, 15,091,983 weighted edges, dt = 0.1 ms. Treat as read-only upstream.
- FlyGym 2.1.0 (EPFL NeuroMechFly v2, MuJoCo 3.9) installed as a pip package in the `flygym` env — provides body, 3D world, compound-eye vision.
- `external/flywire_annotations/Supplemental_file1_neuron_annotations.tsv` — public FlyWire cell-type annotations (`root_id`, `cell_type`, `side`, …), used to label neurons and select them by type. Codex (codex.flywire.ai) requires Google login, so this file is the substitute.
- `external/Fly-Brain-AI/` — clone of community project `neilt93/Fly-Brain-AI` @ `64bdbaf`: a Brian2 whole-brain ↔ FlyGym 1.2.1 closed loop, with the looming experiment replicated here. **No license**, so run it locally but never copy its code into our deliverables or redistribute it; our scripts only import it. Two local repairs were needed:
  - Its `brain-model` submodule has no `.gitmodules`, so `philshiu/Drosophila_brain_model` @ `91bdd1e` was cloned into `external/Fly-Brain-AI/brain-model/` by hand. Its `Connectivity_783.parquet` is byte-identical to Eon's (same SHA-256).
  - Gitignored `plastic-fly/data/*_v4_looming.npy` files are regenerated by `fba_reconstruct_ids.py`.
- `external/Pugliese_cpg_2025/` — clone of `github.com/smpuglie/Pugliese_cpg_2025` @ `faee4b0` (Pugliese et al. 2025 VNC rate model + MANC/FANC/BANC T1 data). **No license**: import only, never copy code. Its `configs/paths/*.yaml` hold the authors' cluster paths; `vnc/run_pugliese.py` builds the OmegaConf config itself with a local `data_dir` instead of using Hydra path templates.

User-facing docs are in Chinese: `report.md` (findings, verified results, error log, licenses) and `embodiment_plan.md` (routes A/B/C). Keep new user-facing text in Chinese and keep the 【官方】/【社区】/【实测】/【推测】 labeling convention (official / community / measured / inference); never report results that were not actually run.

## Environments (separate conda envs; they cannot be merged)

`setup.sh [cpu|gpu|flygym]` builds them. `gpu` follows the official README and is untested here.

- `brain-fly-cpu` — Python 3.10, numpy 1.26, brian2 2.9, **pytorch from conda-forge**. Do not `pip install torch` here: it causes `OMP: Error #15` (duplicate libomp with conda-forge llvm-openmp).
- `flygym` — Python 3.12, numpy 2.x, flygym 2.1.0, plus pip torch/pandas/pyarrow (no OMP conflict in this env). Used for anything touching FlyGym, including the connectome closed loop.

- `fba` — Python 3.11, flygym **1.2.1** (old Gymnasium API, mujoco 3.2.7, dm_control), brian2 2.9, cython. Used only for Fly-Brain-AI and `fba_*.py`. Not in `setup.sh`; it was created with `conda create -n fba python=3.11 && pip install "flygym==1.2.1" brian2 cython pandas pyarrow h5py imageio imageio-ffmpeg pyyaml matplotlib scipy`.

- `fba` also has flyvis 1.2.0 + torch (pip). Its pretrained models live in `site-packages/flyvis/data/results/flow/0000/000`. The official `download_pretrained_models` timed out (httplib2 ignores the proxy), so they were fetched with curl from the same Drive API endpoint; the SHA-256 matched.
- `flybody` — Python 3.11, flybody (git), mujoco 3.13, dm_control 1.0.46, numpy 1.26. Used only by `flight/export_flight.py`; run it with `MUJOCO_GL=glfw`. Also used by `scratch/probe_rl_speed.py`.
- `flybody-tf` — clone of `flybody` plus tensorflow 2.16.2, tensorflow-probability 0.24.0, tf-keras 2.16.0 (flybody's `[tf]` extra pins TF 2.8/reverb, which have no macOS arm64 wheels). Used only by `flight/policy_rollout.py`. The trained policies (TF 2.8/TFP 0.16 SavedModels returning a TFP distribution) load only after `flight/tfp_compat.py` aliases the old full-path TypeSpec names (`tensorflow_probability.python.distributions.independent.Independent_ACTTypeSpec` → `tfp.distributions.Independent_ACTTypeSpec`).
- `vnc-sim` — Python 3.13, JAX 0.9.2 (CPU only), diffrax 0.7.0, hydra/omegaconf; created from `external/Pugliese_cpg_2025/environment.yaml` (`conda env create -f …`, which also `pip install -e` the repo). Used only by `vnc/run_pugliese.py`.

`import pyarrow` must precede `import torch` (upstream note about a libarrow conflict).

## Memory safety — read before running anything

The dev machine is a 16 GB M1 Pro and has frozen once from OOM. Normal runs peak at 2.5–4.3 GB; this includes the Fly-Brain-AI real-brain looming run, despite its README claiming ~8 GB. Rules:

- Run one simulation at a time; never launch experiments in parallel.
- Wrap runs with `scratch/memguard.sh <limit_MB> <logfile> cmd...`, which kills the process tree over the limit and appends `exit=… peak_tree_rss_MB=…` to the log.
