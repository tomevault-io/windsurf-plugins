# ezPay 電子發票首次申請完整指南

## 適用對象

- 台灣已完成公司或商業登記的營業人（有統一編號）
- 第一次申請電子發票（尚未取得電子發票開立資格）
- 選擇使用 ezPay（簡單行動支付）作為電子發票加值服務中心

## 重要觀念

### 什麼是電子發票字軌？

電子發票字軌是發票上的編號，由 2 個英文字母 + 8 個數字組成（例如 KK-12345678），每張發票的字軌號碼都是獨一無二的。營業人必須先申請取得字軌號碼，才能開立電子發票。

### 字軌的期別制度

- 字軌以「期別」為單位，每兩個月為一期（1-2月、3-4月、5-6月、7-8月、9-10月、11-12月）
- 每組字軌有 50 個號碼，1 組 = 50 張發票
- 財政部會在偶數月的 18 號後開始配號（例如 7-8 月期的字軌在 6/18 後配發）

### 相關平台角色說明

| 平台/機構 | 角色 |
|---|---|
| 國稅局（各地稽徵所） | 審核電子發票字軌申請文件，核發開立資格 |
| 財政部電子發票整合服務平台（大平台） | 配發字軌號碼（取號）、存證發票資料 |
| ezPay 電子發票加值服務平台 | 協助開立/傳輸電子發票至大平台，自動化取號與空白字軌上傳 |

## 完整申請流程總覽

```
階段一：前置準備
  ├── 1. 準備工商憑證
  ├── 2. 註冊 ezPay 測試區帳號
  ├── 3. 註冊 ezPay 正式區帳號
  └── 4. 取得發票樣張與解密驗證證明

階段二：紙本送件（首次申請，無法純線上完成）
  ├── 5. 填寫申請文件
  └── 6. 送件至國稅局

階段三：取號與設定自動化
  ├── 7. 國稅局審核通過
  ├── 8. 財政部大平台首次取號
  ├── 9. 設定 ezPay 委任自動取號
  └── 10. 啟用空白字軌自動上傳

階段四：正式開立電子發票
  └── 11. 在 ezPay 正式區開立發票
```

## 階段一：前置準備

### Step 1：準備工商憑證

工商憑證是公司在網路上的電子身分證，後續多個步驟都需要使用。

- 申請網址：經濟部工商憑證管理中心 https://moeaca.nat.gov.tw
- 需準備：公司印章、讀卡機
- 如果已經有工商憑證，確認是否在有效期限內
- 需安裝 HiCOS 卡片管理工具：https://moica.nat.gov.tw/rac_plugin.html

> **提醒**：如果公司有委任會計師，可以請會計師代為處理後續的申請流程（包含文件準備與送件），但通常會額外收取委託申請的服務費用，請事先與會計師確認費用與範圍。

### Step 2：註冊 ezPay 電子發票測試區帳號

測試區用來產出申請所需的發票樣張，不會產生實際費用。

- 測試區網址：https://cinv.ezpay.com.tw
- 點右上角「申請」，填寫企業名稱、統一編號、姓名及電話等等（務必填真實資料）
- 輸入商店資料，商店名稱填「品牌名稱」
- 登入後到「管理設定」→「使用狀況」→「申請費率方案」（任一方案，測試免付費）
- 到「管理設定」→「發票字軌號碼設定」→ 手動新增測試字軌，各欄位填法如下：

  | 欄位 | 填寫內容 |
  |---|---|
  | 字軌類型 | 選「一般稅額」 |
  | 年份 | 當年民國年（例如 114） |
  | 期別 | 選對應的目前期別（例如目前是 3-4 月則選「3-4 月」） |
  | 字軌 | 任意填兩個英文字母，例如 `AA` |
  | 起迄號碼 | 起號填 `00000001`，訖號填 `00000050`（即 1 組 50 張） |
  | 發票類別 | 選「一般稅額」 |

### Step 3：註冊 ezPay 電子發票正式區帳號

- 正式區網址：https://inv.ezpay.com.tw
- 同樣完成企業會員註冊與商店建立
- 記下：統一編號、商店代號、商店名稱、HashKey、HashIV（API 串接會用到）

### Step 4：取得發票樣張與解密驗證證明

#### 4-1：電子發票證明聯樣張

在 ezPay 測試區操作：

1. 到「銷項發票作業」→「開立發票」
2. 開立一張測試發票（B2B 類型）
3. 開立完成後到「列印電子發票」→「查詢」→ 勾選發票 →「熱感列印」
4. 列印出來的就是電子發票證明聯樣張

#### 4-2：二維條碼解密驗證成功證明

**方法一（推薦）：請 ezPay 客服協助**

將測試區開出的發票樣張 PDF 寄到 cs@ezpay.com.tw，信件主旨寫「申請二維條碼解密驗證」，ezPay 會處理好後把解密證明寄回給你。

**方法二：自行在整合服務平台測試區操作**

1. 註冊財政部電子發票整合服務平台測試區帳號：https://wwwtest.einvoice.nat.gov.tw
2. 登入後到「人員帳號及權限管理」→「QRCode 解密驗證」
3. 輸入發票樣張上 QR Code 的加密字串
4. 用正確的密碼種子解密
5. 驗證成功後截圖存檔

> **注意**：測試區帳號與正式區分開，需另外註冊。密碼種子必須與 ezPay 測試區設定的一致，否則解密會失敗。如果遇到困難，建議直接用方法一請 ezPay 協助。

#### 4-3：其他需要的截圖（Step 5 應檢具文件會用到）

如果會開立 B2C 電子發票（賣給消費者），還需要在 ezPay 測試區截圖以下畫面，後續填寫申請書的應檢具文件時需要附上：
- 「以載具索取」系統功能畫面截圖（用於證明可輸入共通性載具）
- 「愛心碼捐贈電子發票」系統功能畫面截圖（用於證明可接受捐贈碼捐贈）

## 階段二：紙本送件

### Step 5：填寫申請文件

> **重要**：首次申請電子發票字軌**必須紙本送件**，無法純線上完成。線上申辦的「增加/減少字軌」功能僅限已有電子發票開立資格的營業人使用。

#### 需要的文件清單

所有申請書表可從財政部稅務入口網下載：
https://www.etax.nat.gov.tw/etwmain/etw212w/detail/6304811861295645753

| 文件 | 是否必備 | 說明 |
|---|---|---|
| 電子發票字軌號碼申請書（主文件） | ✅ 必備 | 蓋公司大章 + 負責人小章 |
| 書表1 - 使用電子發票承諾書 | ✅ 必備 | 蓋公司大章 + 負責人小章 |
| 書表2 - 電子發票開立系統自行檢測表 | ✅ 必備 | 蓋公司大章 + 負責人小章 |
| 電子發票證明聯樣張 | ✅ 必備 | 從 ezPay 測試區列印取得 |
| 二維條碼解密驗證成功證明 | ✅ 必備 | 從 ezPay 客服或整合服務平台測試區取得 |
| 書表3 - 感熱紙切結書 | 看情況 | 使用感熱紙印發票才需要，純雲端免附 |
| 書表4 - 總機構明細總表 | ❌ 免附 | 無分支機構者免附 |
| 書表5 - 委託加值服務中心事務委任書 | 看情況 | 有工商憑證可線上授權免附，無工商憑證才需紙本（需 ezPay 蓋章，約 2 週） |
| 書表6 - 委託專業代理人事務委任書 | ❌ 免附 | 一般不需要 |

#### 主文件（電子發票字軌號碼申請書）填寫說明

**受理機關**：填你公司登記地址所屬的國稅局稽徵所
（例如：財政部北區國稅局中壢分局稽徵所）

**申請項目勾選**：

- ☑ 一、申請整合服務平台帳號、密碼
  - 有工商憑證者不需勾此項
  - 無工商憑證者勾「無工商憑證但需取用電子發票字軌號碼」
- ☑ 二、電子發票字軌號碼「每期」預估使用數量
  - 勾「一般稅額計算」→「首次申請」
  - 填寫組數（1 組 = 50 張發票，建議先填 1 組）
- ☑ 三、配號方式
  - 勾「期配」（每兩個月一期，一般中小企業選這個）
- ☑ 五、委任加值服務中心下載電子發票字軌號碼相關業務

**應檢具文件欄位**（首次申請必填，字軌數量異動申請者免填）：

此欄位分兩種類型，請勾選符合你公司情況的那一種：

- **第一種：僅開立 B2B 或 B2G 電子發票** → 完全不需填寫此欄
- **第二種：開立 B2C 電子發票（含同時開立 B2B/B2G）** → 一般公司選這種，依下表逐項確認

> 選第二種後，需逐項確認是否已備妥以下文件，準備好的項目勾「是」：

**必備文件**：

| 項目 | 如何勾選 |
|---|---|
| 使用電子發票承諾書（書表1） | 已填寫並準備好 → 勾是 |
| 「電子發票證明聯」樣張 | 已從 ezPay 測試區列印 → 勾是 |
| 二維條碼加密驗證資訊解密驗證成功證明 | 已取得（ezPay 客服提供或自行驗證）→ 勾是 |
| 共通性載具條碼掃描設備或畫面證明 | 無實體店面者：截圖系統可輸入載具的畫面後列印 → 勾是（勾選「○經營無實體店面營業人檢附可輸入共通性載具之畫面」） |
| 可接受捐贈碼捐贈電子發票之證明文件 | 截圖系統可輸入捐贈碼的畫面後列印 → 勾是（勾選「○網頁或功能畫面」） |
| 電子發票開立系統自行檢測表（書表2） | 已填寫並加蓋印章 → 勾是 |

**傳輸方式**：

| 項目 | 如何勾選 |
|---|---|
| 使用 Turnkey 方式傳輸者，填上線通行碼 | 使用 ezPay 加值服務中心者 → 勾否，不填 |
| 由加值服務中心或總機構代傳者，填名稱及統編 | 如已在財政部整合服務平台線上完成委任申請 → 勾否，不需再填；若走紙本委任（書表5）則填：簡單行動支付股份有限公司 / 54352706 |

**其他應檢具文件**（一般皆為否，逐項確認即可）：

| 項目 | 一般情況 |
|---|---|
| 「銷貨退回、進貨退出或折讓證明單」樣張 | 否 |
| 電子發票證明聯採用感熱紙切結書（書表3） | 純雲端開立者 → 否 |
| 第三方公正檢驗機關出具檢測報告 | 否 |
| 總機構代其他固定營業場所申請字軌明細總表（書表4） | 無分支機構者 → 否 |
| 電子發票載具發行機構核准證明 | 否 |
| 委託加值服務中心事務委任書（書表5） | 有工商憑證並已線上授權 → 否；無工商憑證且走紙本委任 → 是 |
| 委託專業代理人事務委任書（書表6） | 否 |

**申請人欄位**：

| 欄位 | 填寫內容 |
|---|---|
| 營業人名稱 | 公司全名 |
| 統一編號 | 8 碼統一編號 |
| 稅籍編號 | 查閱公司成立時財政部國稅局寄送的函件，裡面會載明；若找不到再打電話到所屬稽徵所詢問 |
| 營業地址 | 公司登記地址 |
| 負責人姓名 | 負責人全名 |
| 蓋用營業人章 | 蓋公司大章 |

**聯絡方式**：填聯絡人、手機、電話、email（很重要，帳號密碼和審核結果會寄到這）

**委任加值服務中心欄位**：

> **強烈建議**：直接在財政部電子發票整合服務平台線上申請委任，不要走紙本。紙本委任需 ezPay 用印，約需 2 週作業時間；線上委任當天即可完成。

**方法 A（推薦）：在財政部大平台線上委任 → 申請書此欄免填**

步驟如下：

1. **ezPay 後台啟用委任下載**
   - 登入正式區 → 右上角「發票管理」→ 左側「管理設定」→「發票字軌號碼設定」→「委任下載新增」→ 點「啟用」

2. **財政部大平台設定授權**
   - 登入財政部電子發票整合服務平台 → 以工商憑證登入
   - 先完成主憑證登錄：「營業人功能選單」→「基本資料」→「營業人憑證登錄作業」→「新增」→ 選「工商憑證」→ 插卡輸入 PIN 碼 →「登錄憑證」
   - 設定授權：「營業人功能選單」→「接收方式及授權」→「設定接收方式及授權」→「新增」→「發票字軌相關業務」
   - 接收方式選「加值服務中心/總公司接收」
   - 加值服務中心統編填 **54352706**（ezPay）
