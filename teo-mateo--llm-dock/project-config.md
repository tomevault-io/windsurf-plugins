# LLM-Dock - Developer Guide

## Project Overview

LLM-Dock is a Docker Compose-based dashboard for managing local LLM inference services. It supports llama.cpp (GGUF models) and vLLM with automatic GPU detection, model discovery, and Open WebUI integration.

**Access points:**
- Dashboard: `http://localhost:3399`
- React frontend (v2): `http://localhost:3399/v2`
- Open WebUI: `http://localhost:3300`

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Flask 3.0, Python 3.10+ |
| Frontend (v2) | React 19, Vite 7, Tailwind CSS 4 |
| Frontend (legacy) | Vanilla JS + Jinja2 templates |
| Orchestration | Docker Compose v2 |
| Database | SQLite (benchmark results, chat history) |
| GPU | NVIDIA Container Toolkit, nvidia-ml-py3 |

### Key Dependencies (`dashboard/requirements.txt`)
`flask`, `flask-cors`, `docker`, `pyyaml`, `nvidia-ml-py3`, `python-dotenv`, `jinja2`, `requests`, `mcp[cli]`, `sympy`, `schemdraw`

### Frontend Dependencies (`dashboard/frontend/package.json`)
`react`, `react-dom`, `react-router-dom`, `react-markdown`, `katex`, `@tailwindcss/vite`, `vite`
