# CLAUDE.md — 法考网课字幕结构化笔记

## 项目目标

把法考网课字幕整理成三个版本的学习笔记,对应**预习 → 深入 → 冲刺**三个复习阶段。

使用者复习节奏很紧(每科 1–3 天,每天最多 10 小时)。笔记的价值在于**快速定位考点**和**避免背错**,不在于完整复述课程。**篇幅超标等同于失败**——读不完的笔记价值为零。

本 vault 同时是 Obsidian 库,输出的 md 要符合下方 Obsidian 约定。

> 本文件只规定**产出什么**。分组、排序、幂等跳过、输入校验、并发控制由外部驱动脚本负责,不在本文件范围内。

---

## ⚠️ 五条铁律(优先级高于本文件其他一切规定)

违反任一条,产出即作废重跑。这五条**不接受任何理由的例外,包括"补充的内容确实是对的"**。

1. **字幕里没有的,笔记里就没有。** 知识点、法条编号、例题、口诀、答题模板、金句——一律只能来自输入字幕。你的法律知识只用于**读懂**字幕,不用于**补全**字幕
2. **数字只能抄,不能想。** 期限、比例、年龄、金额、条文号、要件个数,照字幕写。字幕含混或自相矛盾时标 `【?】` 并附原文片段,**不得用你记得的正确答案覆盖**
3. **表述宁笨不改。** 字幕的法律表述哪怕拗口、不像教科书,也保留其原意。不得"顺手改成标准说法"——这是最难发现的一类错误
4. **不确定就标,不要圆场。** 拿不准一律 `【?】`。空缺可以事后补,错误会被当成对的背下去
5. **只有篇幅上限,没有下限。** 输入短就输出短,不得为凑长度扩写

使用者**尚未学过**这些科目,没有能力识别错误。一处错误会被原样背进考场。**空缺的代价远小于错误。**

## 分科规范

本文件只写**八科通用**规则。每科的差异(篇幅上限、专属输出要求、学理处理、专属 ASR 错字表)写在:

```
00_规范/<部门法>.md
```

处理某科时**必须同时读取本文件与该科规范文件**。两者冲突时,**以分科文件为准**。

⚠️ **本次运行未实际读到分科规范文件时,中止并报告,不得用通用规则代跑。**
缺了分科文件会丢掉篇幅上限、专属输出要求、专属 ASR 错字表,而**产出看起来完全正常**——
这是最容易发生、也最难事后察觉的一种失败。开始处理前先声明你读到了哪两个文件。

├── 00_样本/反例/
├── 00_素材/                        ← 只读,永不修改
│   ├── 三国法/                     ← ⚠️ 三个子学科混装在一个目录里
│   ├── 民法李建伟/  民法孟献贵/      ← 双老师,老师名直接连在科目名后
│   ├── 刑诉向高甲/  刑诉左宁/
│   └── 刑法/ 民诉法/ 行政法/ 理论法/ 商经知/
├── 三国法/<子学科>/                ← 三国法按子学科分三个输出目录
│   ├── _预习.md
│   ├── _冲刺.md
│   └── 专题NN <专题名>.md
└── <部门法>/
    ├── _预习.md
    ├── _冲刺.md

`00_素材/` 下的文件**只读**。不要修改、移动、删除、重命名其中任何文件。

## 主线老师

**每科只有一条主线(一位老师)**,记录在该科规范文件中。

- 该字段为 `【待填】` 且该科存在多位老师素材时,**中止并询问**,不得自行选择,不得同时读取多个目录
- 该科只有一位老师时,此字段可留空
- 其他老师的素材仅在**显式指定单个专题**时处理,产出到 `<部门法>/补充/`,文件名加老师标识

⚠️ 补充笔记**不参与** `_预习.md` 和 `_冲刺.md` 的汇总。并入会让双老师的体系差异和口诀冲突重新污染主线。

## 输入

通常由驱动脚本按专题拼接后传入。若需自行分组,规则如下。

素材文件名实例:

```
001_国际法 - 专题01：导论_clean.txt
002_国际法 - 专题02：国际法主体和国际法律责任（一）_clean.txt
003_国际法 - 专题02：国际法主体和国际法律责任（二）_clean.txt
```

⚠️ **不要解析整个文件名。** 分隔符风格不统一(下划线 / 空格 / 短横 / 全角冒号),分部号可能是中文括号、也可能不存在。只抽两个数字:

| 抽取项 | 规则 |
|---|---|
| **集号** | 文件名开头的连续数字 |
| **专题号** | 字符串 `专题` 之后的连续数字 |

**集 ≠ 专题。一个专题可能跨多集。**

1. 按**专题号**分组
2. 组内按**集号升序**排列,一起读入,合并产出**一个**专题笔记
3. 专题名取自组内第一个文件
4. 不要逐集产出笔记,也不要把多个专题合并成一个文件

### ⚠️ 一个目录内含多个学科时必须二级分组

**三国法一个素材目录里混装了国际公法、国际私法、国际经济法三个子学科**,
靠文件名区分,而**三个子学科各自都有「专题01」**。

只按专题号分组会把三份不相干的内容合并成一个文件——而合并后的笔记
**看起来仍然是完整的**,这种错误极难察觉。

处理三国法时按 **子学科 + 专题号** 分组,判断规则见 `00_流程/目录映射.md`
(⚠️ 匹配顺序不可颠倒)。

⚠️ 自行分组时**先输出分组结果**(专题号 → 文件列表)供确认。分组错误会产出残缺笔记且难以察觉:某专题只处理了前半部分时,笔记本身看起来是完整的。

### 输入格式已知情况

- `_clean.txt` **有单行版也有多行版**(部分素材已按句末标点断行,便于处理)。
  两种都不代表内容残缺
- ⚠️ **换行是清洗产物,不是语义分段。** 不要把断行当成段落或话题切换,按语义连读即可
- 句子可能被字幕切割点打断,同样是拼接产物
- 溯源片段照抄原文时**不要跨行截取**;若必须跨行,片段中不保留换行

### ⚠️ 字数的统计口径

**本文件所有「字数」一律指字符数(一个汉字算 1 个),不是字节数。**

UTF-8 下一个汉字占 3 字节。把字节数当字数,会让**篇幅上限虚高约 3 倍**、
**输入校验阈值放松约 3 倍**,而且两处都朝着最坏的方向错。

> 实测案例:国际公法专题03 三集合计实际 **39,344 字**,按字节统计报出 **123,173**,
> 38% 上限从 14,951 虚增到 46,806 —— 按后者产出的"笔记"会比原始字幕本身还长,
> 直接反掉「读不完的笔记价值为零」这个前提。

统计时排除换行与空白:

```
tr -d '\n\r' < 文件 | wc -m       # ✅ 字符数
wc -c < 文件                      # ❌ 字节数
```

⚠️ 报出字数后**先自查量级**:一集网课字幕通常 8,000–25,000 字。
若单集报出 7 万以上,几乎一定是把字节当成了字数。

### 输入校验

> **任一输入文件字数 < 2000,中止并报告文件名,不生成笔记。**

上游清洗脚本存在"广告词整行删除 + 单行文件 = 命中即整集清空"的缺陷。若不校验,会拿着空文件产出一份**结构看起来完整但内容缺失**的笔记——这是静默失败,事后极难发现。

## 生成顺序

```
第一步:逐专题产出深入版(专题之间无依赖)
   ↓ 该部门法全部深入版完成(屏障)
第二步:从深入版汇总 _预习.md 和 _冲刺.md
第三步:回填分科规范文件
```

预习版和冲刺版是**部门法级汇总文件**,**只从深入版提炼,不回头读字幕**。这样三版内容一致,也省 token。

汇总时若发现深入版之间**结论冲突**(同一概念不同表述、结论不一致),标 `#冲突` 并列出双方出处,**不要自行选择一方**。

## 考点分级(三版通用)

| 级别 | 判定依据 |
|---|---|
| ★★★ | 老师明说"必考""年年考";或考情显示已连续多年考察 |
| ★★ | 老师明说这是考点("这是考点""勾一下""考试会考") |
| ★ | 老师提及但未标注重要性 |

⚠️ **老师完全未表态的不标星。** 重要性判断必须来自老师或考情,**不得来自你的先验知识**。

三版沿用同一级别,不得出现级别不一致。

## 主观题相关内容(条件产出)

> 本科是否涉及主观题,见分科规范文件。

**唯一规则:老师讲了就写,老师没讲就整节省略。**

- 老师给出**答题步骤、答题结构、答题模板、主观题提示** → 深入版末尾设 `## 主观题` 小节保留
- 老师给出**适合采分的表述、要求原样记住的句子** → 收入冲刺版「必背金句」
- ❌ 老师未讲的,**不得自编答题模板,不得自造采分句式**。自编的答题结构无法验证,会让使用者形成错误答题习惯,危害大于空缺
- 没有主观题内容时**不出现该小节**,也不要写"本专题未涉及主观题"之类的占位说明

## 三版规格

### 深入版 `<部门法>/专题NN <专题名>.md`

主力材料,一个专题一个文件。

- 保留所有**考点**,每个考点标注星级。非考点的背景解释、理论溯源可压缩或省略;确有助于理解的用引用块保留,不超过三行
- **法条依据置于该考点开头**。老师给出法条编号或条文表述的提到最前;⚠️ 老师未给出的**不得自行补充**,可标 `【原文未引法条】`
- 保留考点提示、真题及选项解析
- 保留精讲书页码,统一格式 `P9`、`P13`(字幕中的"第九页"须转换),并在 frontmatter 记录范围
- 老师举的案例:**保留案例本身,压缩叙述**。一到两行说清,不复述完整故事
- 易混淆点一律用对比表格
- 老师明确说"这是考点""考试会考""勾一下""口诀""易错"的,全部保留并标注
- 考情信息("这个考过两年了""这几类还没考过")视为重点内容,必须保留
- 详略按考点重要性分配,不追求各专题篇幅一致
- 老师讲了主观题方法时设 `## 主观题` 小节;未讲则不设
- 文件末尾附「字幕校对说明」

**篇幅上限:该专题输入总字数的 X%(X 见分科规范文件)。**

⚠️ **计算基数只含正文考点内容。** 下列不计入字数,**不得为压字数而删减它们**:

| 不计入 | 原因 |
|---|---|
| frontmatter | 元数据 |
| 「字幕校对说明」 | **回填分科错字表的唯一数据源**,删了这条链就断,且事后无法察觉 |
| `_自检/专题NN.md` | 独立文件,本就不在笔记内 |

⚠️ 超标时的删减次序,不得颠倒:

1. 先删**规范没要求、自己额外加的结构**(章节回顾表、内容小结、学习建议之类)
2. 再压缩案例叙述(保留案例,压到一两行)
3. 再压缩非考点的背景解释
4. **仍然超标 → 停下报告,不要自行舍弃考点。** 按「篇幅上限的调整判据」由使用者决定是否上调上限

⚠️ **只有上限,没有下限。** 不得为凑长度补充内容——输入短就输出短。任何"至少多少字"的要求都会直接诱发编造。

⚠️ 但**「没有下限」不等于越短越好**。压缩比**低于上限的 2/3** 时,必须在自检报告中
说明原因,并**逐节列出本专题的知识点清单与笔记的对应情况**。

> 实测案例:国际公法专题03 输入 39,344 字(比专题02 多 29%),上限 38%,
