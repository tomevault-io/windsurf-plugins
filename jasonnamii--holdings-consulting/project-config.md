# Holdings Consulting Engine

홀딩스 컴퍼니(지주회사) 범용 컨설팅 스킬. 7축 전문지식 + 10대 판단분기점 기반.


## Skill Boundaries

- **하는 것** — 지주회사 5시나리오(신규설립·전환·운영·승계·해외) × 7축(법률·세무·재무·거버넌스·전략·사례·프로세스) 컨설팅. 2026.5 법령 반영.
- **안 하는 것** — 재무모델(→financial-model)·BP 작성(→bp-guide)·정책기획(→policy-planning)·계약 검토(→contract-consulting)·투자유치 진단(→investment-skill)

## 3단계 실행 흐름

```
①가이드 → ②핑퐁 → ③리포트
```

### ① 가이드 제시

**가이드 조건부:** 형이 해당 분야 경험자(이전 대화에서 확인 또는 명시)이면 ①가이드 스킵 → ②핑퐁 직행. 미확인 시에만 가이드 제시. 7축 전체 설명 → 시나리오 라우팅 후 필수축 2\~3개만 설명으로 축소.

스킬 발동 시 클라이언트에게 전체 진행 가이드를 먼저 제공:

```
"홀딩스 컴퍼니 컨설팅을 시작합니다.

[진행 순서]
1. 현황 파악 — 몇 가지 질문을 드립니다 (약 10~15문항)
2. 구조 진단 — 7축 분석을 수행합니다
3. 리포트 — 맞춤 컨설팅 보고서를 생성합니다

준비되셨으면 시작하겠습니다."
```

가이드 제시 후 즉시 Phase 1 질문 시작. 승인 대기 불필요.

### ② 핑퐁 대화

→ `references/pingpong-questions.md` 참조

**핵심 원칙:**

- 3 Phase(목적·현황 → 구조대안 → 제약·실행) 순서
- Phase당 1\~3문항씩 묶어서 질문 (한 번에 전부 쏟지 않음)
- 답변에 따라 불필요한 질문 자동 스킵
- **10대 판단분기점**이 핑퐁의 라우팅 로직 → `§4` 참조

**Phase 1 완료 후 필수 액션:**

1. 시나리오 판별 → `§2` 시나리오 라우팅
2. 복합 시나리오 시 주/부 확정 + 형에게 1줄 고지
3. 중점 축 결정 → 해당 스포크만 로드
4. Phase 2 질문 필터링 (스킵할 질문 사전 결정)

### ③ 리포트 생성

→ `references/report-template.md` 참조

핑퐁 완료 후 md 리포트 자동 생성. 저장: SAVE_CHAIN(프로젝트폴더 → VAULT/\_inbox → mnt/outputs)

## §1. 7축 지식 체계

컨설팅의 지식 기반. 필요한 축만 선택 로딩.

축핵심스포크1. 법률·규제공정거래법 요건, 설립방식 5종, 행위제한, 금융지주법→ `references/knowledge-legal-tax.md §1`2. 세무·조세익금불산입 4단계, 연결납세, 가업승계, 적격분할→ `references/knowledge-legal-tax.md §2`3. 재무·자본구조지분설계, 4대 수익원, NAV 디스카운트→ `references/knowledge-finance-governance.md §1`4. 거버넌스이사회, 상법398조, CP, 소수주주 보호→ `references/knowledge-finance-governance.md §2`5. 전략·운영전환목적 5유형, 시너지, 전환타이밍→ `references/knowledge-strategy-cases.md §1`6. 사례국내 5사+해외 4사+실패 2건→ `references/knowledge-strategy-cases.md §2`7. 프로세스5단계 컨설팅, 핑퐁, 리포트→ `references/consulting-process.md`

**축 로딩 규칙:** 핑퐁 답변에서 관련 축이 식별되면 해당 스포크만 로드. 전체 로드 금지(토큰 낭비).

## §2. 시나리오 라우팅

핑퐁 초기 답변으로 시나리오를 판별하고, 이후 흐름을 분기.

시나리오판별 조건중점 축핵심 산출물**신규설립**기존 법인 없음 or 백지 설계1→2→3→5구조설계안 + 세무시뮬**기존전환**복수법인 존재, 지주전환 검토1→2→4→6전환 로드맵 + 리스크분석**운영최적화**이미 지주체제, 효율 개선3→4→5→6포트폴리오 리밸런싱 + 거버넌스 개선안**승계설계**세대교체 목적 명시2→1→4→3승계 로드맵 + 세제최적화안**해외구조**해외법인 비중 큼1→2(해외)→3해외홀딩스 구조안 + CFC분석

**복합 시나리오 처리:**

- 주시나리오 1개 확정 + 부시나리오 최대 1개 보조 로딩
- 흔한 복합 패턴: 승계+전환(가장 빈번), 전환+해외, 최적화+승계
- 복합 시 중점 축 = 주시나리오 축 + 부시나리오에서 주시나리오에 없는 축만 추가

## §3. 해외 비교 프레임 (2026.5 갱신 — Pillar 2 반영)

한국법 중심이되, 클라이언트가 해외 구조를 검토할 경우 즉시 비교 제공.

| 항목 | 한국 | 미국(DE) | 일본 | 싱가포르 | 홍콩 | UAE | 아일랜드 |
|---|---|---|---|---|---|---|---|
| 지분율 의무 | 30~50% | 없음 | 없음 | 없음 | 없음 | 없음 | 없음 |
| 부채비율 제한 | 200% | 없음 | 없음 | 없음 | 없음 | 없음 | 없음 |
| 법인세(명목) | 22% | 21%+주 | 30% | 17% | 16.5% | 9% | 12.5% |
| **Pillar 2 GloBE 15%** | **IIR 2025.7·UTPR 2026.7·QDMTT 2025.7** | **QDMTT 2025** | **IIR 2024·UTPR 2025** | **QDMTT 2025** | **QDMTT 2025** | **DMTT 2025** | **QDMTT 2024** |
| 배당 비과세 | 30~100% | 100%(10%↑) | 제한적 | 전액 | 전액 | 전액 | 전액 |
| 양도소득세 | 있음 | 있음 | 있음 | 없음 | 없음 | 없음 | 12.5% |
| 상속·증여세 | 최고 50% | 있음 | 있음 | 없음 | 없음 | 없음 | 33% |
| 다국적 시 실효세율 | 15% 이상 | 15% 이상 | 15% 이상 | **15%로 상승** | **15%로 상승** | **15%로 상승** | 15% 이상 |

**⚠️ Pillar 2 핵심**: 다국적 매출 7.5억 유로↑ 그룹은 모든 관할국에서 **실효세율 15% 최저 보장**. 싱가포르 17%·홍콩 16.5%·UAE 9%·아일랜드 12.5% 명목세율의 매력 사실상 소멸. 한국 모회사가 IIR로 부족분 과세 → 차라리 한국 본사 유지 + 운영 SPV만 분리 모델 검토.

## §4. 12대 판단분기점 (2026 갱신)

핑퐁 대화의 라우팅 로직. 각 분기점에서 답변이 달라지면 컨설팅 방향이 전면 변경됨.

| # | 분기점 | 영향 |
|---|---|---|
| 1 | 자산 5,000억 이상/이하 | 공정거래법 적용 여부 → 규제 강도 결정 |
| 2 | 인적분할 vs 물적분할 | 지분구조·세무·소수주주 이슈 전면 변경. **2025 §382의3 충실의무로 물적분할 리스크 급증** |
| 3 | 지분율 경계값 (50%·20%) | 배당세 급변 → 지분 설계 방향. 50%↑ 100%, 20~50% 80%, 20%↓ 30% |
| 4 | 금융업 포함 여부 | 금융지주회사법 별도 적용. 2025~26 핀테크 출자 15%·PEF 운영 허용 |
| 5 | 승계 목적 유무 | 가업승계 특례·증여세 전략 활성화 (600억 한도) |
| 6 | 상장 vs 비상장 | 의무 지분율 차이 (현행 20/40, 신규설립·전환 30/50) |
| 7 | 해외 자회사 유무 | CFC·이전가격·조세조약 검토 |
| 8 | 순환출자 존재 여부 | 해소 의무, 전환 복잡도 |
| 9 | 단층 vs 다층(중간지주) | 규제 준수 방식, 경영 유연성 |
| 10 | 전환 vs 신규설립 | 기존 법인 재편 vs 백지 설계. **신규설립·전환부터 30/50 지분율 적용** |
| 11 | **자기주식 보유량** (2025 신설) | 상법 3차 개정 — 자사주 1년 내 소각 의무. 우호지분 전략 무력화 |
| 12 | **사익편취·일감몰아주기 노출** (개정) | 총수일가 20%↑ 지분 계열사 + 50%↑ 자회사로 규제 확대. 매각·정리 의무 |
