# AGENTS.md

- Work directly on `main`; create a branch only when the user explicitly requests one.
- When a branch is requested, use `chore/`, `fix/`, or `feat/`; never `codex/`.
- Force-push rarely; prefer clean commits and normal pushes.
- Prefer clearer names over comments.
- Remove comments that restate the code.
- If a comment is needed, keep it one line and explain why.
- Colors: author theme tokens in `oklch()` (wider gamut + perceptually-uniform lightness, matching
  Tailwind/shadcn v4). Prefer it over `hsl()`/hex for new/edited color values. Derived tokens use
  relative color syntax `oklch(from var(--x) l c h / a)`. `hsl()`/hex still resolve (the tokens are
  format-agnostic), but new work should be oklch.
- CSS-first: prefer modern CSS and native platform elements — `:has()`, `:focus-within`, sibling
  combinators, container/style queries, `field-sizing`, `@starting-style`, the `popover` attribute,
  `<dialog>` — over React state, effects, and event handlers for interaction, sizing, and motion.
  Declarative CSS is server-rendered, honours the `--duration-*`/`--ease-*` reduce-motion tokens,
  and ships no JS. Guard Limited features (anchor positioning, scroll-driven animations,
  `interpolate-size`, `if()`) behind `@supports` with a JS fallback. Drop to JS only for genuinely
  stateful or async logic. See the CSS-first practice rules below.

# Control UI registry — agent cheat-sheet

> Generated by `bun run docs:agents` from the registry catalog. Do not edit inside the markers.

## How to use this registry

- Discover: `GET http://127.0.0.1:3000/api/registry` (or the static `http://127.0.0.1:3000/r/agent-index.json`) → the agent-friendly index.
- shadcn catalog: `http://127.0.0.1:3000/r/registry.json` → the official registry schema used by shadcn tooling.
- Read one item: `GET http://127.0.0.1:3000/api/registry/<id>` → source files, install command, and deps.
- Search: `GET http://127.0.0.1:3000/api/registry/search?q=<query>`.
- Skin anatomy: `http://127.0.0.1:3000/r/skin-contract.json` is the complete generated scope, part, state, paint, adornment, and semantic-family contract; do not guess selectors.
- Install: run the item's `install` command (`npx shadcn@latest add <url>`). Installed files are yours to own and edit.
- Skinning: a skin is additive CSS + a `skin.config`; install a skin pack to restyle every component at once.
