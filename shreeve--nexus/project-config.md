# AGENTS.md — Working on Nexus

> Generate a standalone Zig lexer + LR parser from one grammar file. Self-hosting, no runtime.

Nexus reads `.grammar` files and emits standalone Zig modules containing a combined lexer + LR parser (LALR(1) by default, SLR(1) via `--slr`). The engine contains zero language-specific code.

Start here if you are modifying the generator, the grammar DSL, `nexus.grammar` itself, or any generated output.

## First rules (file ownership)

- **`src/nexus.zig`** — hand-written generator engine (~7,300 lines). Edit freely.
- **`src/parser.zig`** — **generated** from `nexus.grammar`. Never hand-edit. Regenerate with `./bin/nexus nexus.grammar src/parser.zig` and commit alongside any `nexus.grammar` change.
- **`src/lang.zig`** — hand-written companion to `src/parser.zig` (Tag enum + lexer wrapper for the self-hosted frontend).
- **`nexus.grammar`** — the grammar DSL expressed in its own format. The block comment at the top is the canonical S-expression schema — the binding contract with `GrammarLowerer`.
- **`test/golden/*.zig` and `test/golden/*.sexp`** — part of the correctness contract. Regenerate only when output changes are intentional and reviewed.

## Mental model

```
{lang}.grammar + {lang}.zig
        ↓
    src/nexus.zig (generator)
        ↓
    generated parser.zig
```

Self-hosting: `nexus.grammar` is parsed by `src/parser.zig`, which was itself generated by Nexus from `nexus.grammar`.

## Critical invariants

- **Engine stays language-agnostic.** No language-specific branches in `src/nexus.zig`. Per-language behavior belongs in the `{lang}.zig` module.
- **Generated output is deterministic.** Same grammar → same bytes, every run. A determinism test enforces this.
- **Bootstrap converges.** Regenerating `src/parser.zig` from `nexus.grammar` with the current binary must reproduce the checked-in file exactly. A fixed-point test enforces this.
- **Lowering is strict.** `GrammarLowerer` rejects malformed Sexps with `error.ShapeError`. No silent defaults, no heuristic shape inference. A negative-shape suite enforces this.
- **Output shape is part of the contract.** Do not reorder generated declarations, rename emitted helpers, or alter Sexp shapes unless the change is intentional and reviewed through golden diffs. Downstream grammars and consumers depend on byte-exact emitted structure.
- **Grammar is the source of truth.** Prefer declarative mechanisms (`@as`, `@op`, `@infix`, `@code`, guards, actions) over `{lang}.zig` logic. The Zig side is an escape hatch for what can't be expressed declaratively.

## Change map

- Touched `nexus.grammar`? → `./bin/nexus nexus.grammar src/parser.zig`, then `zig build test`. If the frontend S-expression golden (`test/golden/nexus.sexp`) drifted, run `./test/run --update` and commit grammar + parser + golden together.
- Touched lowering or codegen in `src/nexus.zig`? → Expect goldens under `test/golden/` to change. Review each diff before committing; don't bulk `--update`.
- Changed AST shapes? → Update `test/golden/*.sexp`, the adverse tests, and the lowerer negative-shape suite in `src/nexus.zig`.
- Changed token classification or `@as` behavior? → Re-run all validated language grammars (Zag, Slash, MUMPS); conflict counts may shift.
- Touched anything in `src/lang.zig` the frontend depends on? → Rerun `zig build test` to catch bootstrap drift.

## Commands

```bash
zig build -Doptimize=ReleaseSafe          # recommended for running nexus: ~8× faster than Debug, safety checks kept
zig build                                 # Debug (fast compile, slow runtime)
zig build test                            # full 36-test suite
zig build test-lowerer                    # lowerer negative-shape suite only
./test/run --update                       # regenerate goldens after intentional changes
./bin/nexus --dump-sexp <grammar>         # inspect the frontend's Sexp tree
./bin/nexus nexus.grammar src/parser.zig  # regenerate the self-hosted frontend
```

## File map

- `src/nexus.zig` — generator engine
- `src/parser.zig` — self-hosted frontend (generated)
- `src/lang.zig` — lang module for `src/parser.zig`
- `nexus.grammar` — grammar DSL in its own format; opens with the canonical Sexp schema
- `test/{basic,features,zag,slash,mumps,ruby}/` — grammar + lang module per language
- `test/golden/` — byte-exact golden files (`*.zig` and `*.sexp`) including `nexus.sexp`
- `test/adverse/` — bad grammars that must produce errors
- `test/run` — orchestrator for 36 tests: goldens, compile checks, determinism, adverse, self-hosted Sexp goldens across every in-repo grammar, bootstrap fixed point, and the lowerer negative-shape suite

## Validated Languages

| Language | Grammar | Lang Module | Lexer Wrapper |
|----------|---------|-------------|---------------|
| MUMPS | `test/mumps/mumps.grammar` | `test/mumps/mumps.zig` | Yes — pattern mode, indent dots, spaces exclusion |
