# 老胡 AI 视觉作品生产系统

本文件是当前项目的唯一顶层规则入口。每次在本项目中处理影视创意、剧本、分镜、AI 图片、AI 视频、封面、剪辑、发布复盘、模板、案例或经验材料，都优先读取并遵守本文件。

本项目采用动态迭代规则：旧规则、旧模板、旧目录或旧提示词写法如果已经被新版本替代，并且继续保留会干扰执行，可以删除，不默认归档保留。原始输入、已发布作品、成功案例、失败案例和发布复盘默认保留，因为它们是经验证据。

当前共享执行规则的主入口是 `02_共享资产库/00_核心规则手册.md`。导演级影视创作的总控入口是 `02_共享资产库/05_工具流程/导演级影视创作总控流程.md`。本文件负责顶层方向和目录纪律，核心手册负责创作执行细则，导演总控流程负责把灵感、故事、文戏、武戏、画面、剪辑、资产和 AI 生成串成一条导演链路。不要再把同一类创作规则散落到多个新文件里；能合并进核心手册、导演总控流程或核心 skill 的，优先合并。

当前项目只保留 6 个核心 skill 入口：

```text
laohu_ai_visual
laohu_script_writer
laohu_visual_assets
laohu_video_prompt
laohu_vibe_creating_prompt
laohu_generation_review
```

后续新增或修改 skill 必须以 `laohu_` 开头。除非某个能力已经大到会明显拖慢扫描和调用，否则不要再为基础设定、氛围画质、人物表情、画面内容、图片生成、图片验收、封面、剪辑、发布分别建立零散 skill；优先沉淀进上述核心 skill。

## 1. 核心定位

这个项目不是提示词收藏夹，也不是横向素材库，而是老胡的 AI 影视作品生产系统。

### 1.0 助手文本交付边界

助手在本项目中的生产职责默认全部是文本交付：故事设计稿、剧本、文字分镜、资产清单、图片资产提示词、音频资产提示词、故事板图片提示词、视频提示词、封面提示词、生成复盘和规则文件。除非老胡明确要求助手直接调用某个生成工具并产出实际素材文件，否则不得自行生成图片、音频、视频、分镜图、故事板图或其他二进制素材。

项目语言中的动作词必须按以下含义执行：

```text
“创建 / 生成图片资产” = 编写图片资产提示词和资产使用说明，由老胡自行生成并上传图片。
“创建 / 生成音频资产” = 编写音频资产提示词和使用说明，由老胡自行生成、选择并上传音频。
“生成分镜” = 输出文字分镜表、镜头任务或故事板图片提示词，不直接生成分镜图片。
“生成视频提示词” = 输出可复制的视频提示词，不直接生成视频。
“调用 @资产” = 在文本中写显性占位符，等待老胡绑定素材，不代表本地已经有对应文件。
```

错误做法：把“需要 A02 品牌定帧资产”理解成助手应直接创建 PNG，再在文本里写“已创建”或本地文件路径。正确做法：在统一结果文件中写完整的 `【A02 品牌定帧图片资产提示词】`、用途、验收条件和 `【@A02 品牌定帧】` 占位符。只有老胡实际回传生成结果后，才能把该素材登记为已存在资产；不能把提示词完成误写成素材已经生成。

### 1.0.1 测试内容原创与老胡品牌归属

用于模型测评、公开展示、教程或账号发布的测试内容，默认采用原创虚构人物、组织、品牌、产品、包装、Logo、宣传语、车辆型号、门店和界面。真实作品可以提供摄影、剪辑、动作或材质规律参考，但不得直接使用或近似复刻其品牌名、Logo、角色 IP、吉祥物、广告语、标志性产品外形、包装和商业视觉系统。该规则用于降低误用第三方知识产权与商业识别的风险，不代表仅改名即可构成法律上的绝对免责；视觉结构和文本也必须原创。

凡测试内容需要品牌、产品文字或商业设计，统一从老胡自有识别发展：名称使用 `老胡`，英文使用小写 `laohu`，账号署名使用 `老胡用AI赚钱`；行业变体使用 `老胡 + 中文品类` 或 `laohu + 英文品类`，例如 `老胡香氛 / laohu parfum`、`老胡汽水 / laohu soda`、`老胡汽车 / laohu motors`。不得为每道测试随机发明与老胡无关的品牌。字体、材质、色彩和行业气质可以变化，但老胡品牌锚点必须可识别；没有合理品牌载体的镜头不强塞悬浮 Logo。

未经老胡明确授权，不得再发明新的品牌名称、简称、图腾、徽章或第四品牌锚点。老胡已经有固定 Logo 图片，内容为英文名 `laohu`；凡画面需要 Logo，统一显性调用 `【Logo参考@老胡Logo】`，直接使用该图片，不重新设计 Logo，不生成 Logo 提示词，不描摹重画，不改字体结构、原始颜色和横纵比例，不重着色或材质化，也不用文字描述另造近似标。正式资产提示词和视频提示词只负责写清固定 Logo 在包装、片尾、车标、店招或界面中的位置、尺寸，以及它随载体产生的真实透视、缩放、遮挡和受光；产品、包装和版式可以原创设计，但不得借此改造 Logo 本体。

用于综合模型测评、公开商业样片或行业测试时，镜头里凡由真人模特承担可识别表演、商品操作、穿戴、口播、行走、运动或手脚特写，都必须先建立对应人物资产，不能只用一行外貌文字让不同模型随机选角。具体可识别人物按同一编号交付 `人物形象资产提示词 + 人物设计资产提示词`；只承担背景密度的匿名人群可建立群像人物资产。性别不属于测试变量时，单人模特优先使用成年女性；多人场景由女性承担主要视觉、关键动作或主要台词，再自然穿插成年男性，形成有主次的混合群像。若测试题明确检验男性角色、家庭身份、特定职业或人口结构，则服从测试目标，不为了偏好改坏控制变量。

### 1.0.2 参考素材必要性

参考素材不是每个模态都必须配齐。只有某段外部内容本身需要被准确复现，且仅靠文字无法公平锁定时，才创建对应参考资产。音频默认不做参考资产：普通 BGM、环境音、动作音和随机声场直接写进视频提示词，由模型按同一文本生成。只有固定歌曲 / MV、指定人物音色或声纹、现成对白口型同步、必须复现的节奏结构等情况，才创建并上传音频参考。不能因为视频里有音乐或音效，就机械新增音频资产提示词。

项目的第一组织维度是“作品”，不是“剧本工作台”“提示词工作台”“素材工作台”。一个正式作品就是一个独立项目目录。这个作品从创意、剧本、人物、视觉设定、图片资产、视频提示词、生成素材、剪辑成片、封面发布到复盘，全部放在同一个作品目录里。

项目的第二组织维度是“共享资产”。共享资产包括模板、视觉语言、模型适配、案例经验、工具流程和 skill。共享资产不是为了好看地存资料，而是为了帮助下一个作品更稳定地产出。作品复盘中产生的新经验，也要反向更新共享资产。

每次处理材料，都要同时判断四件事：

1. 它属于哪个作品；如果还没有作品，就先建立作品目录或归入 `00_输入原料/`。
2. 它处在作品链路哪一环：创意、剧本、视觉设定、图片资产、视频提示词、生成素材、剪辑、封面、发布还是复盘。
3. 它是否能沉淀成共享资产：模板、词典、模型适配规则、成功案例、失败案例或工具流程。
4. 它如何让下一次作品产出更好，而不是只让当前这一次好看一点。

## 1.1 根本目的判断规则

处理老胡的任何需求时，不要只停留在表面说出的操作、数字、功能名、镜头点子或局部修复点上，必须主动判断背后的根本目的。

老胡后续发来的口述、反馈、参考、碎片想法、纠错、示例和不满意点，都不能当成孤立命令处理。必须从老胡给出的内容内部出发，先理解他真正想表达的东西，再做合理扩展、发散和经验吸收。

执行顺序：

```text
先读老胡原话和上下文
→ 提炼他表面说了什么
→ 判断他真正想表达的创作目标、体验目标或系统目标
→ 从这些内容中扩展可落地的规则、边界、样例或方法
→ 判断沉淀位置：当前作品 / 核心规则手册 / 对应 laohu_ Skill / 模板 / 检查脚本
→ 再执行具体产出或修改
```

### 1.1.0 创作者意图契约与创意成熟循环

影视创作开始时，先建立 `创作者意图契约`，再选择三幕式、起承转合、短剧反转、英雄旅程或其他结构。契约至少回答：老胡真正想让观众经历什么；这个题材为什么值得由老胡来做；哪些人物、事件、价值、台词或结果不可改变；哪些部分允许专业模块主动发挥；这部作品明确不想变成什么。信息能够从上下文可靠推断时直接形成内部契约，只有互斥方向会改变作品核心定位、成本或风险时才向老胡确认。

创意不能从一个模糊想法直接跳进格式模板。默认执行 `创意成熟循环`：

```text
创作者意图契约
→ 产出机制真正不同的候选，而不是同一梗概换措辞
→ 指认最容易出现的普通答案和类型俗套
→ 用最强反对意见攻击人物动机、因果、价值、原创性和可拍性
→ 沿人物选择继续推演二阶后果，并寻找能被画面和声音证明的细节
→ 按观众承诺、情绪潜力、持续发展、原创性和可生成性选择方向
→ 再用结构理论诊断、组织和加压
```

结构是诊断和组织工具，不是创意发动机。不得先套结构，再为了填满节拍强造冲突、反转、高潮或人物行为；也不得因为一个方案格式最完整，就误判它比仍在成长但更有生命力的方案更好。

创意选定后，关键段落建立内部 `观众认知状态账本`：观众此刻知道什么、暂时相信什么、正在问什么、预测下一步是什么、第一眼看哪里、主要感到什么，以及本节拍改变了哪一项。它用于校验故事是否持续更新观众，不要求把八项机械写进每个镜头，更不能把这些内部分析词直接投喂给视频模型。

### 1.1.1 商业作品意图推断与卖点场景化

当需求属于电商广告、TVC、产品宣传、品牌片、带货视频、商业样片、门店获客或其他需要促成购买 / 咨询 / 记忆 / 行动的内容时，即使老胡只给了产品、时长和几个动作，也不能直接当作商品展示片执行。展示片回答“它长什么样”；商业广告还必须回答“谁在什么处境下需要它、它解决什么、观众凭什么相信、看完应该做什么”。

商业任务进入剧本、资产或视频提示词前，先在内部完成最小商业简报：

```text
转化目标：希望观众看完记住、相信、咨询、试用、购买还是分享什么。
目标人群：谁最可能有这个需求，他当下在什么使用场景。
购买矛盾：他现在有什么真实不便、风险、不满或取舍。
核心承诺：这一条片只让观众记住的一个主利益。
支撑卖点：一般只选 2-4 个能支撑主承诺的功能、结构、材料或服务优势。
相信证据：每个卖点要用什么可见场景、人物选择、身体反馈、接触结果、对比或声音证明。
文案任务：哪句负责钩住需求，哪句命名卖点，哪句完成品牌与行动出口。
声称边界：哪些是已知事实，哪些是本次原创虚构产品设定，哪些不能凭空声称。
```

` 卖点场景化 ` 不是让模特拿着产品念参数，而是把 `用户处境 → 触发问题 → 产品机制参与 → 可见 / 可听物理结果 → 用户获得的好处` 拍成一条因果链。口播、旁白、字幕和广告语只负责帮观众命名画面已经证明的利益，不能代替证据。如果老胡没给文案且文案对转化承重，编剧模块默认主动设计钩子、卖点句和行动句，不得因输入未写而直接交付无讲述的漂亮空镜。

真实产品没有提供性能、成分、价格、疗效、认证或比较证据时，不得编造客观参数和绝对化声称；原创虚构测评产品可以为了测试明确设计功能结构与使用表现，但仍要让卖点、资产结构和画面物理互相对得上。

六个核心 skill 在商业任务中的主动责任：入口识别转化目标并路由；编剧建立购买矛盾、承诺、证据、文案和行动出口；视觉资产让产品结构、模特身份和场景具备证明卖点的能力；视频提示词把每个卖点编译成可见因果和可感声音；VC 优化不得压掉购买理由、证据和 CTA；复盘同时验收观看欲、信任、卖点理解与行动意图，不只评画质和一致性。

扩展和发散必须区分“已明确事实”和“创意留白”。老胡、故事设计稿或剧本已经写明的人物关系、动机、台词、事件因果、关键道具和结果是硬约束，后续不得违背；没有写明的剧情连接、动作相位、表演、调度、镜头、声音、光影、环境反馈、节奏和情绪实现属于授权创意空间，默认由当前专业模块主动补全，不为普通创意选择反复询问。新增创意要写入当前产物和交接包，保证后续继续继承。只有真实增加外部成本、法律 / 安全 / 发布风险、文件结构范围，或面对两个互相排斥且会改变作品核心定位的方向时，才向老胡确认。
