# AGENTS.md

Morph UI is a docs site for copy-paste React components built on the View Transition API and React's `<ViewTransition>`. Next.js 16 (App Router), React 19.3+, Tailwind v4, shadcn/ui.

## Commands

```bash
npm run dev       # next dev
npm run build     # next build, also type-checks
npm run lint      # oxlint
npm run format    # prettier --write .
npm test          # CSS snippet, monochrome and skill checks
npm run skill     # rebuild skills/morph-ui/ (the agent skill)
```

Always run `npm run format` and `npm run build` after changes, and `npm run skill` after changing a component, an example, `morph.css`, the entries or `src/lib/reference.ts`. Verify visible behavior in a real browser; don't ask the user to check.

## Layout

| Path                            | What it holds                                                                                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/registry/`                 | The components people copy. One `.tsx` per component.                                                                                                                                                                    |
| `src/registry/morph.css`        | The one CSS file: a small set of `vt-*` classes (motion, lists, sizing, surfaces, direction, stagger) that every component composes.                                                                                     |
| `src/components/docs/examples/` | One runnable demo per component, with its sample data. Shown under Usage.                                                                                                                                                |
| `src/app/`                      | Routes: `/` Introduction (intro plus every component as a live demo), `/getting-started` setup, theme and classes, `/skill` the Skill page (installing the agent skill), `/[slug]` one page per component, pre-rendered. |
| `src/app/globals.css`           | Imports Tailwind, shadcn, then `morph.css`.                                                                                                                                                                              |
| `src/components/docs/`          | The docs site UI: sidebar, code tabs, navigation, theme toggle.                                                                                                                                                          |
| `src/components/ui/`            | shadcn components. Only the docs site uses these.                                                                                                                                                                        |
| `src/lib/entries.ts`            | The component list (slug, category, title, description, uses).                                                                                                                                                           |
| `src/lib/sources.ts`            | Reads component, CSS and example sources at build time.                                                                                                                                                                  |
| `src/lib/reference.ts`          | The class list, theme snippet and recipes (`SkipOnScroll`, `RouteTransition`), shared by the docs pages and the skill.                                                                                                   |
| `skills/morph-ui/`              | The agent skill. Generated by `npm run skill`; never edit it by hand.                                                                                                                                                    |
| `scripts/build-skill.mjs`       | Builds the skill from the registry, examples, `morph.css`, entries and `reference.ts`. The prose lives in `scripts/skill/*.md`.                                                                                          |

## Registry components

These are the product. Rules:

- **React's `<ViewTransition>` only.** Never call `document.startViewTransition()`; it interrupts React's transitions. Changes animate only inside `startTransition` (or Suspense / `useDeferredValue`); a plain `setState` doesn't.
- **Reusable API.** Data comes in through props. Sample data and demo controls live in `src/components/docs/examples/`, not in the component.
- **Self-contained.** Plain HTML elements and Tailwind classes only. No imports from `@/components/ui` or `@/lib`, no `cn()`. The only import is `react`. Icons are small inline SVGs of our own (16px grid, 1.5 stroke, `currentColor`), defined at the top of the file; demos use the same style. Never add an icon package.
