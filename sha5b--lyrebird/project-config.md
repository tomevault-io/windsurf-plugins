# AGENTS.md — Lyrebird

Operational conventions for agents working in this repo. Read this first.

## Layout

- `pipeline/` — offline Python (uv-managed, `pipeline/.venv`): harvests xeno-canto,
  fits the physical syrinx model, trains the critic, builds the galaxy assets.
  Source: `pipeline/src/lyrebird_pipeline/`.
- `app/` — SvelteKit + TypeScript: realtime syrinx synth (AudioWorklet), mic analysis,
  Threlte 3D galaxy. Static assets generated by the pipeline live in `app/static/lyrebird/`.
  `inventory.json` there is the canonical whole-file checkpoint; `inventory/<id>.json`
  shards + `inventory/index.json` are the app's lazy view of it (pickers read the index,
  a bird's full entry loads on selection).
- `data/` — `inventory.json` (hand-authored, canonical), `learned-inventory.json`
  (generated by `learn`), `discovered-species.json`.
- `docs/` — the research base. **`docs/08-implementation.md` is normative**: both halves
  implement it. `docs/09` and `docs/10` are evidence records — read them before changing
  anything they measured.

## Hard constraints (violating these breaks the project)

- **No audio is ever *shipped*. Audio may now be *retained* where the licence permits**
  (owner decision, 2026-08-01, replacing the blanket rule below). The project is
  non-commercial and open source, so CC's NC and SA clauses impose nothing it does not
  already satisfy, and keeping a file is not redistributing it. `harvest --keep-audio DIR`
  and `harvest.audio_may_be_cached` gate it per recording: **NoDerivatives is refused**
  (9.7 % of the corpus — everything downstream produces derived measurements) and **an
  unrecorded licence is refused** (absence of a licence is not permission). 90.3 % of the
  production store's 10 184 recordings pass, and all 10 184 carry a recordist, so
  attribution exists for every kept file. Pinned by `harvest.self_test`.
  **The browser still gets none of it** — the owner declined shipping audio in the app on
  the same day, so `out/audio-cache/` and its siblings stay local, out of every asset set.
  The reason to keep audio is measured, not convenient: an external model (Perch, BirdNET)
  and any per-syllable re-measurement need the waveform, and docs/23 §23.6 could only run
  on the 6 453 of 10 184 recordings whose audio still existed.
- **The older blanket rule, kept for context — with one owner-sanctioned exception.**
  `harvest.py`'s decode → describe → delete loop remains the default and is
  load-bearing for licensing. Exception (owner decision, 2026-07-30): `sources fetch
  --keep-audio <dir>` may cache staged audio under `pipeline/out/audio-cache/` for
  the current training phase, so re-training doesn't re-download archives. The cache
  is local-only (`out/` is gitignored), feeds `harvest_directory` on re-runs, is
  never read by the app or copied into assets, and is **deleted when the training
  phase ends**. iNatSounds' own terms (no redistribution) are compatible with this.
  *(That 2026-07-30 exception was folded into the general policy above on 2026-08-01:
  xeno-canto harvests now take `harvest --keep-audio` under the same per-licence gate. An
  earlier version of this bullet ended "xeno-canto harvests still delete immediately",
  which the entry above contradicts.)*
- **Licensing (`LICENSE`, `NOTICE.md`).** The project is **non-commercial**: its own code
  and prose are CC BY-NC-SA 4.0. That licence covers only what is ours. **The harvested
  recordings are not ours to relicense** — each carries a per-recording Creative Commons
  licence from its own recordist, and that licence plus the recordist's name must travel
  with the recording and with anything derived from it (`CREDITS.md` in each store).
  Third-party dependencies keep their own licences; note that `harmonypy` (the optional
  `analysis` extra) is **GPL-3.0-or-later** and BirdNET is itself CC BY-NC-SA. Adding a
  dependency or an archive means adding a row to `NOTICE.md`.
- **Never delete `pipeline/out/harvest*` stores.** They are the only copies, gathered
  under xeno-canto rate limits.
- **No torch weights ship to the browser.** Assets are plain JSON/f32; the app must work
  with no Python process running.
- **The synthesiser stays physical and interpretable**; learned components analyse and
  score, they never generate audio.
- **Honesty rule (docs/08 §8.5):** every claim in the UI carries a confidence label;
  novel sounds are "unlabelled: real acoustics, no documented function".
- **Parity:** `app/scripts/verify-parity.mjs` must stay **18/18** (this read 14/14 and
  docs/09 §9.4 read 12/12; the script reports 18 cases) and `render-syllable.mjs`
  44/44 after any synth-adjacent change.
- Evidence discipline: changes to fitting/objectives/spaces are judged by **pre-registered
  metrics** on a fixed store, and negative results are documented, not deleted (see
  docs/09 §9.7, docs/10 §10.5 for the pattern).
